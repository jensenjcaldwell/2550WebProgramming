Project 4: Responsive Web Site-CSS Theme and Refactor (100 Points)
First step: Return to Project 3 and download your previous files, then upload them here. At least, unless you want to do that project all over again. Only then should you start implementing Project 4.

Part I: Standardized Setup (10 Points)
To prepare for the advanced layout and responsiveness requirements, your page must meet these technical organization standards:

Mobile Meta Tag: You must include <meta name="viewport" content="width=device-width, initial-scale=1.0"> in the <head>.

Root Structure: All primary layout elements (<header>, <aside>, <main>, <footer>) must be direct children of a single parent container (e.g., a <div id="wrapper"> or the <body>).

ID Integrity: Every <section> must have an id that matches an anchor link in your navigation menu exactly.

II. The "Theme Override" Stylesheet (30 Points)
Create a new "Theme" that substantially alters the page without modifying your original styles.css.

Inheritance: Do not copy-paste your original CSS. Your theme.css should only contain properties that are being overridden.

Visual Transformation: You must change at least three of the following categories:

Layout Swap: Move the <aside> from left to right (e.g., by changing grid-template-areas).

Color Palette: A complete shift (e.g., Light Mode to Dark Mode).

Typography: Change all primary fonts and spacing.

Component Style: Redefine the visual look of your .card elements (e.g., changing from borders to deep shadows).

III. Dynamic Theme Toggle (30 Points)
Use JavaScript to allow the user to switch themes in real-time.

Trigger: Add a button or link with a unique id.

Injection Logic: When clicked, your script must dynamically create a <link> element pointing to css/theme.css and append it to the <head> of the document.

Toggle State: Clicking the button again must remove the theme link, reverting the site to its original appearance.

IV. Mobile Responsiveness (20 Points)
Ensure the site is usable on smaller screens using media queries.

Viewport Meta: You must include <meta name="viewport" content="width=device-width, initial-scale=1.0"> in your <head>.

The Breakpoint: Implement at least one @media query (e.g., max-width: 768px).

Responsive Layout: On mobile, your CSS Grid must "stack." The <aside> and <main> content should move from a side-by-side layout to a single-column vertical layout.

V. Refactor & Modernization (10 Points)
Variable Usage: Move your primary colors and spacing into CSS Variables (:root { --main-bg: #fff; }) to make theme switching cleaner.

Semantic Check: Ensure all layout issues from previous submissions (alignment, flex-direction errors, or spacing) are corrected using the "best practice" methods (Grid/Flexbox) rather than "hacks" (floats/manual heights).
